# Camperos Games

Tienda de videojuegos desarrollada para la Semana 6 de Desarrollo Frontend I.

## Funciones

- Catálogo cargado desde un archivo JSON.
- Búsqueda y filtros por categoría.
- Carrito de compras dinámico.
- Diseño responsivo con Bootstrap 5.

## Tecnologías

HTML, CSS, JavaScript y Bootstrap 5.
